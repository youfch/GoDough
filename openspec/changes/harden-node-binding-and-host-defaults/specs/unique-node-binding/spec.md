# Spec Delta

## Purpose

定义节点绑定契约：以唯一命名节点（`%`）为目标的成员绑定规则、可绑定成员范围与失败诊断，并明确其与服务注入是相互独立的管线。

## ADDED Requirements

### Requirement: 节点绑定与服务注入相互独立

节点绑定 SHALL 与服务注入（`[Inject]`）保持相互独立的管线：二者互不调用，且可各自单独使用而不依赖对方是否执行。

#### Scenario: 只做节点绑定
- **WHEN** 使用者在节点上只执行节点绑定而不执行服务注入
- **THEN** 标注的节点成员被正确绑定，且不因缺少服务注入而失败

#### Scenario: 只做服务注入
- **WHEN** 使用者在节点上只执行服务注入
- **THEN** 服务被正确注入，且不触发任何节点查找

### Requirement: 唯一命名节点解析

节点绑定 SHALL 以 Godot 的唯一命名节点（`%`）为绑定目标，目标名称由节点绑定特性指定的名称决定，未指定时回退为该成员的名称；SHALL NOT 进行任意路径查找。

#### Scenario: 显式指定名称
- **WHEN** 成员以显式名称标注
- **THEN** 绑定到场景中该唯一命名的节点

#### Scenario: 回退成员名
- **WHEN** 成员未指定名称
- **THEN** 以该成员的名称作为唯一命名去查找并绑定

### Requirement: 可绑定成员范围

节点绑定 SHALL 支持公有与私有属性以及字段；SHALL 跳过索引器与不可写成员（无 setter 的属性、只读字段），且不因这类成员而抛出异常。

#### Scenario: 私有属性绑定
- **WHEN** 节点声明了标注的私有属性（可写）
- **THEN** 该私有属性被绑定到对应唯一命名节点

#### Scenario: 字段绑定
- **WHEN** 节点声明了标注的字段（公有或私有、可写）
- **THEN** 该字段被绑定到对应唯一命名节点

#### Scenario: 不可写成员不导致失败
- **WHEN** 被标注的成员不可写（如无 setter 的属性、只读字段）
- **THEN** 绑定跳过该成员且不抛出异常

### Requirement: 绑定失败的诊断

当成员类型与目标节点类型不符时，绑定 SHALL 抛出包含「成员名 + 期望类型 + 实际类型」的可诊断错误；当目标节点缺失时，默认 SHALL 抛出包含该节点名称的可诊断错误。

#### Scenario: 类型不符
- **WHEN** 成员声明为某类型，而对应唯一命名节点的实际类型与此不符
- **THEN** 抛出包含成员名、期望类型与实际类型的错误

#### Scenario: 目标节点缺失（默认必填）
- **WHEN** 目标唯一命名节点在场景中不存在且未声明可忽略
- **THEN** 抛出包含该节点名称的错误

### Requirement: 缺失节点的可选语义

节点绑定 SHALL 支持显式声明「缺失可忽略」：当成员被标记为可忽略时，目标节点缺失 SHALL 跳过该成员且不抛出异常。

#### Scenario: 缺失可忽略
- **WHEN** 成员被声明为缺失可忽略，且目标唯一命名节点不存在
- **THEN** 绑定跳过该成员且不抛出异常
