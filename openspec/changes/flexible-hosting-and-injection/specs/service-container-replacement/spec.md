# Spec Delta

## Purpose

允许把宿主内置的依赖注入容器替换为第三方容器（例如 Autofac），同时保证框架自身对服务的解析不依赖任何具体容器实现。

## ADDED Requirements

### Requirement: 依赖注入容器可替换
宿主 SHALL 在容器构建之前暴露一个宿主构建器扩展点，允许使用者提供自定义的 `IServiceProviderFactory` 以替换默认容器。

#### Scenario: 使用 Autofac 启动
- **WHEN** 使用者在宿主构建扩展点中提供 Autofac 的服务提供程序工厂
- **THEN** 宿主使用 Autofac 作为容器，且应用注册的服务可被解析

#### Scenario: 未自定义时使用默认容器
- **WHEN** 使用者未提供自定义服务提供程序工厂
- **THEN** 宿主使用内置默认容器启动，行为与当前版本一致

### Requirement: 容器无关的服务解析
框架内部对自身服务（如应用宿主节点提供者、生命周期钩子、引导器）的解析 SHALL 仅通过通用 `IServiceProvider` 能力完成，不假设具体容器类型。

#### Scenario: 自定义容器下生命周期钩子仍触发
- **WHEN** 使用自定义容器启动宿主
- **THEN** 逐帧/输入生命周期钩子与引导器仍被正确解析并按既有节奏调用

#### Scenario: 自定义容器下节点注入仍可用
- **WHEN** 使用自定义容器启动宿主并通过 `[Inject]` 注入服务
- **THEN** 注入从当前服务提供程序解析，不依赖具体容器

### Requirement: 既有注册 API 保持容器无关
框架提供的基于 `IServiceCollection` 的注册辅助（例如接口到实现的多态映射与工厂注册）SHALL 在自定义容器下继续生效，其注册项 SHALL 进入使用者提供的容器。

#### Scenario: 多态映射在自定义容器下可解析
- **WHEN** 使用者用框架的映射辅助把某接口映射到其实现，并改用自定义容器启动
- **THEN** 通过该接口可解析到映射的实现实例

#### Scenario: 工厂注册在自定义容器下可解析
- **WHEN** 使用者用框架的工厂辅助注册服务，并改用自定义容器启动
- **THEN** 每次通过工厂创建的实例符合注册的生命周期语义
