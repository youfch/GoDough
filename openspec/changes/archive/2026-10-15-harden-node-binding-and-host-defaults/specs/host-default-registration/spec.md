# Spec Delta

## Purpose

定义宿主默认服务注册契约：宿主在默认配置下 SHALL 能够解析框架自带的全部服务（含场景管理服务及其依赖），且这些默认注册 SHALL 可被使用者覆盖。

## ADDED Requirements

### Requirement: 开箱可用的默认服务图

宿主 SHALL 在默认服务配置中注册框架自带服务及其依赖，使得使用者**无需任何额外注册调用**即可解析这些服务；其中场景管理服务及其全部构造依赖（Godot API 抽象、主线程调度器、宿主节点提供者、日志）SHALL 均可解析。

#### Scenario: 未做任何额外注册即可解析场景管理服务
- **WHEN** 使用者使用默认宿主配置启动，且未调用任何框架提供的可选注册辅助
- **THEN** 场景管理服务可被成功解析

#### Scenario: 场景管理服务的依赖可解析
- **WHEN** 使用者解析场景管理服务
- **THEN** 其构造依赖（Godot API 抽象、主线程调度器、宿主节点提供者、日志）均已被默认注册并能被注入

#### Scenario: 宿主自身可被解析
- **WHEN** 框架内部服务（如 Godot API 抽象）需要宿主实例
- **THEN** 宿主实例已默认注册，可被解析而不需要使用者显式注册

### Requirement: 默认注册可被覆盖

默认服务注册 SHALL 采用「已存在则不覆盖」的语义，使得使用者可以通过自己的注册替换任一默认实现，且替换后的实现被用于解析。

#### Scenario: 覆盖默认实现
- **WHEN** 使用者在启动配置中注册了某个默认服务的自定义实现
- **THEN** 解析该服务时得到使用者的实现，而非默认实现

#### Scenario: 使用者显式注册与默认注册共存
- **WHEN** 使用者同时调用了框架的可选注册辅助与依赖默认注册
- **THEN** 解析结果唯一且确定，不因重复注册而产生不确定行为
